# Smart Waste Sorter

A modern web application for intelligent waste classification and sorting using machine learning.

## Project Overview

This project helps users classify different types of waste materials into appropriate categories for proper recycling and disposal.

## How to Run This Project

**Prerequisites**

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

**Installation Steps**

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd smart-waste-sorter

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server
npm run dev
```

**Available Commands**

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run code linting
- `npm run preview` - Preview production build
